## 🔍 Monitoring & Debugging

Tools and techniques to help analyze performance and control costs:
- [**dbt artifacts package**](https://github.com/brooklyn-data/dbt_artifacts) → Analyze model runtime performance over time
- [**select.dev**](https://github.com/get-select/dbt-snowflake-monitoring) → Monitor Snowflake warehouse usage and query execution, including credit consumption
- [**Snowflake Query Profile**](https://select.dev/posts/snowflake-query-profile) → Snowflake's built-in visual execution graph for identifying query bottlenecks and inefficiencies

💡 **Tip**: Learning to read the Query Profile is an essential skill for any Analytics Engineer working with Snowflake
